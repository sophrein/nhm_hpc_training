# Franklin and Sanger

Franklin and Sanger are compute servers that form part of the NHM's molecular biology computing facility. They are used mainly for phylogenetics, sequence database searching, and molecular sequence analysis, and are set up to be flexible and interactive. Unlike the NHM HPC and Crop Diversity, **these servers do not use a job scheduler (i.e. SLURM)**.

## Documentation

All information relating to Franklin and Sanger — including how to request access, log in, and use the available software — is maintained in a dedicated user guide:

[**Franklin and Sanger user guide**](https://pgfoster.gitlab.io/g23/franklin/)

Please refer to that guide for full, up-to-date instructions.
