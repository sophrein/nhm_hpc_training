# Getting help

If you get stuck, the best place to go for help depends on which resource you are using. The contacts and links below cover each of the HPC options described in this guide.

## NHM HPC

- **Technology Solutions (TS) Service Desk** — for access requests and technical issues email: [TS-ServiceDesk@nhm.ac.uk](mailto:TS-ServiceDesk@nhm.ac.uk)
- **HPC Users Community** — a [Microsoft Teams group](https://teams.microsoft.com/l/channel/19%3A8aa968ad33924f1e9ac3b4a78862eac4%40thread.tacv2/General?groupId=7e89a01f-f1c5-4886-b494-0ac470650c5a) for help from fellow users and cluster admins, plus the latest cluster news and updates.
- Rob Foster ([robert.foster2@nhm.ac.uk](mailto:robert.foster2@nhm.ac.uk)) is the best contact for issues relating to the NHM HPC.

## Franklin and Sanger

- Managed by Peter Foster ([p.foster2@gmail.com](mailto:p.foster2@gmail.com) / [p.foster@nhm.ac.uk](mailto:p.foster@nhm.ac.uk)), who is available for advice on how to use these servers.
- [Franklin and Sanger user guide](https://pgfoster.gitlab.io/g23/franklin/)

## Crop Diversity

- The [cropdiversity-hpc Slack channel](https://cropdiversity-hpc.slack.com) is usually the best place to ask for help.
- [Crop Diversity HPC documentation](https://help.cropdiversity.ac.uk/index.html)
